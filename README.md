# Le Grand Concours de l'Immo

Jeux en direct à trois équipes (BTS Professions immobilières) : un PC central projeté, un PC par équipe.

- **index.html** : version courte (6 mini-jeux)
- **version-longue.html** : version longue (11 mini-jeux, près de 400 questions)
- **arena.html** : IMMO ARENA, la Ligue des Mascottes : 1re année (B1 ch. 1-5, B2 ch. 1-5, B4 ch. 1, généralités), création de mascottes, 18 jeux dont 7 jeux animés (course, tour, visite piégée, immeuble en coupe, coffre, plateau, duel)

Synchronisation par Supabase Realtime (Broadcast), sans table.

En ligne : https://grem60000-sys.github.io/Grand-Concours-Immo/
